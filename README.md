# Calculadora en Go

>## Sobre este repositorio

Este repositorio documenta el inicio de mi formación autodidacta en programación mediante el desarrollo de proyectos prácticos.

Los detalles técnicos de cada etapa se encuentran documentados en los README de sus respectivas versiones.

---

>## Estado del proyecto

**Estado:** Pendiente de GUI

**Lenguaje:** Go 1.27.0

**Tipo:** Proyecto de formación

---

>## Sobre el proyecto

La calculadora comenzó como un ejercicio para aplicar fundamentos de programación y evolucionó a medida que surgieron nuevos problemas y necesidades.

El objetivo no es únicamente obtener un programa funcional, sino **comprender el código y mejorar progresivamente la solución**.

---

>## Formación y metodología

Mi formación parte de los **conceptos de programación antes de abordar su implementación en un lenguaje concreto**.

Utilizo un **asistente de IA como mentor técnico** para analizar problemas, comprender conceptos, cuestionar decisiones y explorar alternativas durante el desarrollo.

La implementación, las pruebas y las decisiones sobre el código forman parte de mi propio proceso de aprendizaje. Los problemas encontrados se convierten en parte del recorrido y en oportunidades para profundizar en los conceptos.

---

>## Evolución

Cada versión de la calculadora representa una etapa del aprendizaje.

El proyecto se desarrolla mediante un ciclo continuo:

**aprender → aplicar → probar → detectar → resolver → mejorar**

De esta forma, una misma base permite incorporar nuevos conocimientos y revisar progresivamente las decisiones tomadas anteriormente.

---

>## Próximos pasos

Continuar evolucionando el proyecto mientras avanzo en mi formación, incorporando nuevos conceptos de programación y Go y mejorando progresivamente la estructura, mantenibilidad y calidad del código.

Este repositorio es el registro de ese proceso.
